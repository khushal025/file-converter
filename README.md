# File Converter (PDF, Word, Image)

A simple desktop application built using **Python (Tkinter GUI)** that allows you to easily convert files between formats. This tool supports:

- **PDF to Word (.docx)**
- **Word (.docx) to PDF**
- **Image (.jpg, .jpeg, .png, .bmp) to PDF**

The project uses `pdf2docx`, `docx2pdf`, and `Pillow` libraries to handle file conversions.

---

### Features
- User-friendly graphical interface (Tkinter).
- Convert PDF to editable Word documents.
- Convert Word documents directly into PDF.
- Convert images (JPG, JPEG, PNG, BMP) into PDF format.
- Simple pop-up confirmation messages after conversion.
- Cross-platform support (Windows/Linux/Mac).

---

### Tech Stack
- **Python**
- **Tkinter** (GUI)
- **pdf2docx** (for PDF → Word)
- **docx2pdf** (for Word → PDF)
- **Pillow (PIL)** (for Image → PDF)

### Usage

Run the application with:
python next.py 

- Click **"PDF to Word Converter"** → Select a PDF file → Get a Word document.
- Click **"Word to PDF Converter"** → Select a Word file → Get a PDF.
- Click **"Image to PDF Converter"** → Select an image → Get a PDF.
